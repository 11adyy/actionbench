# Hosted evaluations

The live launcher is [actionbench.vercel.app](https://actionbench.vercel.app). Actual experiments run on GitHub Actions, using a standard Ubuntu VM with Docker. This is necessary because Vercel Sandbox builds Docker images but its cgroup mode rejects ActionBench's Docker memory limit. Removing that limit would weaken the experimental controls. GitHub's standard runners are free for public repositories, subject to GitHub's artifact storage and job limits; model API calls are billed by the model provider.

1. In [repository Actions secrets](https://github.com/11adyy/actionbench/settings/secrets/actions), add `OPENAI_API_KEY` as a repository secret. Never put the key in workflow inputs, a commit, or an issue.
2. Open [Evaluate ActionBench](https://github.com/11adyy/actionbench/actions/workflows/evaluate.yml), choose **Run workflow**, then choose `start`. Set an exact model ID and verified prices in USD per million tokens. For `gpt-6-luna` at standard rates, use input `0.10`, cached input `0.01`, cache writes `0.125`, output `0.50`, and reasoning effort `none`; verify these against [OpenAI's current model page](https://developers.openai.com/api/docs/models/gpt-6-luna) before another campaign. The default model budget is USD 8; change it before `start` if needed. Leave campaign as `pilot-001` unless you want a separate study.
3. If the run ends before completing all episodes, run the workflow again with `resume` and the **same campaign ID**. Model and prices are restored from the frozen campaign config; the secret must remain set. If the dollar ceiling is depleted, choose `raise-budget`, enter a **new total ceiling** in `budget_usd`, then choose `resume`.
4. Download the `actionbench-state-...` artifact from the workflow run. It contains `experiment.json`, `artifacts/report.json`, `artifacts/status.json`, the SQLite ledger, package revisions, and recovery metadata. The workflow only freezes a campaign after all planned episodes have terminal results.

Choose `smoke` to verify the official MBPP+ and HotpotQA Docker graders with correct and incorrect controls, without making model API calls. Each run verifies the checked-in task manifest against the official datasets. A campaign pins its source commit and exact Docker image archive; if the image cache is missing, `resume` stops rather than silently changing grader fingerprints. State artifacts expire after 30 days, so download the final one for the paper. The GitHub Free artifact allowance is limited; avoid leaving many old campaign artifacts and image caches in the repository.

If a model request has an unknown outcome, the campaign blocks instead of silently retrying a potentially paid call. Recover the saved artifact, resolve the request with genuine provider evidence using `actionbench resolve-request`, and upload/recreate the state before continuing. This is deliberately a manual audit step; it is not exposed as a one-click workflow action.
