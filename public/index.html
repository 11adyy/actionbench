ActionBench

Evaluaciones reales de skills y actions: modelos reales, Docker con límites de recursos y resultados reanudables.

Abrir evaluaciones Configurar API
  1. Guarda tu clave como secreto OPENAI_API_KEY en GitHub.
  2. En «Abrir evaluaciones», pulsa «Run workflow», elige start y escribe modelo, precios y presupuesto.
  3. Si se interrumpe, vuelve a ejecutarlo con resume y el mismo nombre de campaña. Descarga el artefacto del último run para obtener el informe y el estado.

También puedes elegir smoke para probar los evaluadores oficiales sin consumir tu API.

Guía completa · El alojamiento del runner público es gratuito; el uso del modelo depende de tu proveedor.
